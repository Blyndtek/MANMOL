# ManMol CRM

Demo del centro comercial de ManMol: conversaciones de WhatsApp, seguimiento de leads y clientes, y catálogo de productos y precios.

**Demo:** https://manmol-crm.vercel.app

La interfaz actual usa datos de ejemplo. La conexión real con WhatsApp, la persistencia del CRM y el bot con OpenAI forman parte de la siguiente etapa de desarrollo.
